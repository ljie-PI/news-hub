# vudovn/ag-kit

## 定位与痛点剖析

AG Kit 是一套面向 Google Antigravity 的"智能体工程"套件，用一份完整的 `.agents/` 工作区契约，把规则、技能、专家智能体、工作流、持久记忆、MCP 指引与编排能力打包安装到项目里。它解决的痛点是：AI 编码代理在真实项目中缺乏一致的角色分工、可复现的知识组织和安全护栏，导致行为漂移、上下文丢失以及误执行破坏性命令。AG Kit 以 Antigravity 为主要运行时，试图让代理工程"可审查、可回滚、可验证"。

## 核心架构与技术细节

核心是 Markdown 驱动的组件契约：20 个专家智能体、47 个技能、13 个工作流、6 条规则，外加记忆主题（自报口径）。每个组件都有 SemVer 约束，通过 `manifest.json`、`manifest.lock.json` 与 `DEPENDENCY_GRAPH.md` 保证可复现并检测漂移。亮点是原生安全钩子 `validate-tool-call.mjs`，注册于 `PreToolUse`，仅拦截根目录删除、格式化磁盘、裸盘覆写等高置信破坏模式，放行 `dist/`、`node_modules/` 等常规清理。更新采用 merge-aware 策略并自动备份，支持 `ag-kit update`、`rollback`。需 Node.js 22、Python 3.10。

## 竞品对比与生态站位

相较 Claude Code、Cursor Rules、各类 agent 框架多为通用运行时，AG Kit 明确绑定 Antigravity 为唯一生产兼容运行时，其他工具只能读 Markdown 组件。它提供 `/coordinate`、`/orchestrate` 等斜杠命令做并行编排，站位偏"Antigravity 官方生态的工程化脚手架"，已登上 Trendshift（自报口径）。

## 开发者反馈与局限性

项目 7945 星、1508 分叉，热度不俗。局限明显：运行时行为在 Antigravity 之外不作保证；安全钩子刻意收窄，不替代权限、沙箱或人工审批；默认 MCP 示例含 `YOUR_API_KEY` 占位符会触发告警。文档强调永不自动合并、部署或同步 MCP，凸显其保守可控取向。
