# opengeos/GeoLibre

## 定位与痛点剖析
GeoLibre 是一款免费开源、轻量级、云原生的 GIS 平台，用于地理空间数据的可视化、探索与分析。它由 opengeos 社区（作者 Qiusheng Wu）开发，主打"一处工作区、处处运行"：同一套界面可作为原生桌面应用、Android 应用、浏览器 Web 应用运行，并能嵌入 Jupyter Notebook，同时强调数据保留在本地、保护隐私。它瞄准传统 GIS（如 QGIS、ArcGIS）安装笨重、跨端割裂、数据须上云的痛点，让用户零安装即可在浏览器中处理空间数据。

## 核心架构与技术细节
技术栈以 Tauri v2 + React + TypeScript 为壳，地图渲染用 MapLibre GL JS 与 deck.gl，空间数据处理依托 DuckDB-WASM Spatial 与 Turf.js，实现浏览器内的空间 SQL 与地理处理（自报口径称提供 700+ 免费 GIS 工具，零安装）。特色包括 3D Tiles 渲染、时间滑块、自动图例，以及行星底图——覆盖月球、火星、水星、金星、木卫、冥王星等，并支持逐项目椭球体以校正距离与面积测量。

## 竞品对比与生态站位
相较桌面端的 QGIS、云端的 ArcGIS Online，以及浏览器 GIS kepler.gl、Felt，GeoLibre 的差异化在于全端统一（桌面/移动/Web/Notebook）与本地优先。它延续了 opengeos 生态（leafmap、geemap）的 Python 友好路线，提供 PyPI、conda-forge 包及 Colab 集成，并有插件市场（plugins.geolibre.app）与项目分享服务（share.geolibre.app），生态站位介于开发者工具与终端用户 GIS 之间。

## 开发者反馈与局限性
项目已发布 1.0，采用 MIT 许可，并通过 Zenodo 铸造 DOI 便于学术引用，上架 Microsoft Store、AUR、Flatpak 等多渠道，社区已有 beta 测试者与贡献者反馈。局限方面：DuckDB-WASM 与 deck.gl 在浏览器端处理超大数据集受内存与性能约束；行星底图等特色偏演示性质；作为新兴项目，其工具链成熟度与文档完善度仍需时间验证。
