# palmier-io/palmier-pro

## 1. 定位与痛点剖析
Palmier Pro 是一款面向 AI 的开源 macOS 视频编辑器，口号是「为 AI 打造的视频编辑器」。它切中的痛点是：传统剪辑软件（Premiere、Final Cut、CapCut）与 AI 生成、AI Agent 工作流彼此割裂，创作者需要在生成模型、剪辑软件、脚本工具间反复切换。Palmier Pro 让用户与自己的 Agent 在同一条时间线上「共同生成并编辑视频」，把生成式 AI 直接嵌入剪辑流程。它出自 Y Combinator S24 批次。

## 2. 核心架构与技术细节
项目用 Swift 从零构建，对标 Premiere Pro，属原生 macOS 应用。三大支柱：其一，Swift 原生时间线编辑器，提供专业剪辑体验；其二，内置生成式 AI，可在时间线内直接调用 Seedance、Kling、Nano Banana Pro 等模型生成视频与图像；其三，与 Agent 深度集成——应用运行时会在 `http://127.0.0.1:19789/mcp` 暴露一个基于 HTTP 的 MCP 服务器，Claude Code、Codex、Cursor、Claude Desktop 均可通过 MCP 接入，让外部 Agent 直接操作时间线；也可使用内置 App 内 Agent。这种 MCP 架构使「AI 操控剪辑」成为标准化、可编程的接口。

## 3. 竞品对比与生态站位
相比 CapCut、Premiere 等成熟剪辑器，Palmier Pro 的差异化是「Agent 原生 + 开源」。相比 Runway、Pika 这类纯生成式云工具，它保留了本地专业时间线编辑器的完整能力，并把生成能力作为时间线内的一环。MCP 接口使其天然融入 Claude/Codex/Cursor 的 Agent 生态，站位为「AI 时代的开源剪辑底座」。

## 4. 开发者反馈与局限性
项目 ⭐约 12193（自报口径），采用 GPLv3 授权。开源边界清晰：编辑器本体、MCP 服务器、Agent 聊天均开源，仅生成式 AI 的云端处理为闭源。编辑器免费、无需登录即可像 CapCut/Premiere 一样使用，但生成式 AI 功能需登录并订阅。最大局限是平台门槛极高——仅支持 Apple Silicon 上的 macOS 26 (Tahoe)，将绝大多数用户挡在门外；且核心生成能力依赖付费闭源服务。
