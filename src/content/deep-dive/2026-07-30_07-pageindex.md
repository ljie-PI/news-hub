# VectifyAI/PageIndex

## 定位与痛点剖析
PageIndex 是 VectifyAI 开源的「无向量、基于推理」的 RAG 框架，定位于替代传统向量数据库检索方案。主流 RAG 依赖切块（chunking）与向量相似度检索，但这类方法在专业长文档上常出现语义割裂、检索结果缺乏上下文、无法像人一样通盘理解文档结构等痛点。PageIndex 主张不做向量化、不做机械切块，而是让 LLM 通过推理在文档的树状索引上进行上下文感知的检索，更贴近人类阅读长文档的方式。

## 核心架构与技术细节
项目以 Python 实现，核心是一种 agentic、in-context 的树形索引（tree index）。它把长文档解析成层级化的目录树，LLM 在树上逐层推理定位相关章节，实现 reasoning-based、context-aware 的检索，而非基于嵌入的相似度匹配。近期推出的 PageIndex File System 是文件级树索引层，可让系统在整个语料库而非单份文档上推理，支持百万级文档规模的检索。项目同时提供自托管代码、MCP、API 以及在线 Chat 平台，并给出结合 OpenAI Agents SDK 的 agentic vectorless RAG 示例。

## 竞品对比与生态站位
相较 LlamaIndex、LangChain 等以向量检索为主的 RAG 栈，PageIndex 的差异化在于彻底去掉向量库与切块，用结构化推理换取更强的上下文完整性，尤其适合金融、法律等专业长文档场景。它以「Reads Like a Human」为卖点，在无向量 RAG 这一细分方向上占据先发站位。

## 开发者反馈与局限性
项目 star 数约三万五，社区热度高，被 Trendshift 收录。局限在于强依赖 LLM 的推理调用，检索成本与延迟可能高于纯向量方案；对文档结构解析质量敏感，面对结构混乱的文档时效果需实测。
