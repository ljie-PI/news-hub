# Eclatira

## 事件背景

Eclatira 于 2026 年 9 月 26 日发布，定位为可嵌入应用的实时语音、视觉与行动 Agent。本批冻结数据为 288 票、57 条评论、日榜第 2；调研时官方 GraphQL 对同一帖子 `1237651` 返回值仍相同，热度不等于用户规模或效果验证。

## 核心观点 / 产品机制

官方文档显示，开发者可用组件、客户端库或协议接入：浏览器经单条 WebSocket 发送麦克风及摄像头/屏幕图像，接收语音、转录与工具调用；服务端以短期令牌建会话，REST API 管理 Agent、通话、工具、MCP 和知识库。产品页宣称可接自定义 API、MCP 与三千余应用。需注意口径差异：官网称最高每秒三十帧、端到端低于八百毫秒，摄像头文档却写每秒最多一张静态图、不能跟踪动作，均未见独立测试。

## 社区热议与争议点

评论有四个具体焦点：一名做音视频管线的用户肯定统一语音与视觉能减少拼装痛点；Atul 追问并发输入延迟，Maker Moad 只称“没有”，未给指标；一名语音 Agent 从业者担心工具调用阻塞轮次，产品方称视频独立处理；另一用户询问敏感视频的自托管与驻留，产品方承认目前不能自托管、区域控制仍待推出，并称不存视频流。这些回复属产品方口径，API 用户字段已脱敏。
