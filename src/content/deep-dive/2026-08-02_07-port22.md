# Port22：把 Mac 上的编码 Agent 装进手机

## 一、事件背景

Port22 于 2026 年 8 月 1 日登陆 Product Hunt，斩获当日榜单第三名（Launch of the Day），标语为「Claude Code、Codex 及更多 Agent，尽在你的手机」。创造者 harsha chaganti 表示，自己每天大量使用 Claude Code 与 Codex，最大痛点是启动一个长任务后离开，回来却发现 Agent 早已卡住，只为等他批准一次文件编辑。这一「无声等待」催生了 Port22。

## 二、核心观点 / 产品机制

Port22 把 Mac 上正在运行的每个编码 Agent 投射到手机，让你实时看到哪些在工作、哪些已卡住。关键机制在于：当某个 Agent 需要权限时，手机会震动提醒，而你点击的是 Agent 在实时会话中给出的「真实选项」，而非猜测的按键。它直接挂载到你已经在运行的进程上——无包装、无配置、无需新开终端。免费额度覆盖一台 Mac 与两个会话，且开放全部功能。

## 三、社区热议与争议点

社区反响积极。评论者 Raj Nagulapalle 认为「呈现来自实时会话的真实选项」才是杀手级细节，让人能安全解锁而无需猜测 Mac 端状态，并盛赞「Port 22」这一命名干净利落。作者回应称「从手机端作答」正是他想深耕的方向。争议点集中在赛道拥挤：Conductor、Superset、CodeMote、Remodex、MobileCLI 等竞品林立，如何在同质化中守住差异化仍待观察。

## 四、行业影响与未来展望

「手机远程操控编码 Agent」正成为 2026 年开发者工具的新热点。随着 Agent 自主性提升，人类的角色愈发聚焦于「关键节点的授权与决策」，Port22 抓住的正是这一「人在回路」的刚需。未来若能扩展到 Android、支持更多 Agent 并强化会话可靠性，有望成为移动端 Agent 编排的标准入口。
