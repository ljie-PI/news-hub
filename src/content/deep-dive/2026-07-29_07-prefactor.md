# Prefactor

## 1. 事件背景
Prefactor 于 2026 年 7 月 29 日登顶 Product Hunt 当日榜首，收获 520 votes 与 131 条评论。其标语「Evaluate your AI Agents in real-time」直击当下 AI Agent 落地的核心痛点：大量智能体在离线评测中表现优异，却在真实生产环境里频频失灵。随着 Agent 从演示走向规模化部署，「评测通过、上线翻车」成为团队普遍焦虑，Prefactor 正是瞄准这一鸿沟而生。

## 2. 产品机制
Prefactor 定位为一层「评估层」（evaluation layer），实时为每一次 Agent run 打分。它持续监控智能体在生产中的每次调用，量化输出质量，并主动浮现质量回退（quality regressions）与行为漂移（drift）。相较传统一次性离线基准测试，它把评测从「上线前的一道关卡」变为「上线后的持续护栏」，让团队在问题扩散前及时捕捉异常。

## 3. 社区热议与争议点
131 条评论中，开发者普遍认可「eval 与 production 脱节」是真实且棘手的问题。争议集中在：实时打分的评判标准是否可靠、由谁来定义「质量」，以及在无标准答案的开放场景下，如何避免评分模型本身产生偏差与噪声；也有人担忧额外的监控层会带来延迟与成本开销，质疑其是否会沦为又一个「用 LLM 评判 LLM」的循环。支持者则认为，哪怕评分不完美，能持续暴露漂移趋势就已具备实用价值。

## 4. 行业影响与未来展望
Agent 可观测性与评测正成为 AI 基础设施的新赛道。Prefactor 与 LangSmith、Braintrust 等工具共同推动「持续评估」范式，未来或与 CI/CD、告警体系深度整合，成为 Agent 生产化的标配环节。
