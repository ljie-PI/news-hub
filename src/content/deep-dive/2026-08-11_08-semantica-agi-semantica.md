# semantica-agi/semantica

## 定位与痛点剖析

Semantica 是面向高风险、受监管场景的图原生上下文与决策基础设施，服务人工智能平台、数据工程及审计团队。它针对普通向量检索只找“相似文本”、却难以回答事实来源、因果链和历史状态的问题，把实体、关系、证据与模型决策统一为可查询图，并支持自托管。

## 核心架构与技术细节

项目以 Python 构建端到端管线：数据经摄取、解析、规范化、实体关系抽取、冲突检测和去重后进入知识图谱；其上叠加本体、规则推理、决策记录与 W3C PROV-O 溯源，再输出至向量库、RDF 三元组库或属性图。存储可接 Neo4j、FalkorDB、Oxigraph 等，应用侧提供 REST、MCP、命令行和可视化探索器。核心推理与图构建可不依赖大模型，便于复现结果。

## 竞品对比与生态站位

相较纯向量数据库或一般代理记忆，它的优势是图遍历、双时间事实、冲突标记和可导出的审计链；相较 Palantir 类闭源平台，则以 MIT 许可、可替换后端和本地部署降低锁定。代价是组件面广、依赖多，团队仍需自行设计本体、规则与数据治理，不能把它等同于开箱即用的业务系统。

## 开发者反馈与局限性

近期 GitHub 反馈暴露出成熟度风险：issue #867 指出网页与接口摄取器缺少 SSRF 防护，#868 指出仓库摄取路径存在 GitPython 版本及参数注入面，均已有修复 PR；#864 又称多数公开分块器缺少行为测试。另有导出错误被静默吞掉、部分探索器路由报错等修复在途。说明项目迭代活跃，但用于合规生产前仍应做安全审计、后端兼容验证和回归测试。
