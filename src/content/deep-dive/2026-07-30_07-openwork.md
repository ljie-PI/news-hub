# different-ai/openwork

## 定位与痛点剖析
OpenWork 是一款免费、开源的桌面应用，定位为分享 AI 工作流的平台，官方称其为 Claude Cowork 与 Codex 的开源替代品，支持 macOS、Windows 与 Linux。当前 AI Agent 工具割裂严重：用户在 Codex、Claude Code、Cursor 之间反复配置同一套 skills、MCP 与已连接服务，无法跨工具、跨团队、跨机器复用。OpenWork 试图用统一的能力层解决这一重复配置与协作分享的痛点，让能力「创建一次，处处复用」。

## 核心架构与技术细节
项目以 TypeScript 为主，底层由 opencode 驱动。其核心是一个远程 MCP 服务器，向任意兼容客户端暴露两个工具：search_capabilities 用于发现可用能力，execute_capability 用于执行。用户在 Codex、Claude Code、OpenCode 等客户端一行命令即可接入该 MCP，通过浏览器登录并选择所属组织后，即可把分配到的 skills、插件、MCP 连接以及 Google Workspace、Microsoft 365 能力带入任何 Agent。桌面应用提供专用工作区但非必需。面向组织的 OpenWork Den 作为控制平面，可规模化配置推理、管理成员与团队访问权限。

## 竞品对比与生态站位
OpenWork 直接对标 Anthropic 的 Claude Cowork 与 OpenAI 的 Codex 工作流产品，差异化在于开源、跨平台以及以 MCP 为枢纽的能力共享模型。它不绑定单一 Agent，而是充当各 Agent 之上的能力聚合与分发层，在 MCP 生态中卡位「团队级能力控制平面」。

## 开发者反馈与局限性
项目 star 数约一万八，关注度可观。局限在于强依赖 MCP 生态成熟度与第三方 Agent 的兼容性；能力集中托管带来权限与数据合规考量，其许可为非标准声明，企业采用前需审慎评估合规风险与厂商锁定的可能性。
