# abus-aikorea/voice-pro

## 1. 定位与痛点剖析
Voice-Pro 由韩国小型创业团队 ABUS 开发，定位为 ElevenLabs 的开源免费替代品。它把 YouTube 下载、人声分离、语音识别、翻译与文字转语音（TTS）整合进单一 Gradio WebUI，面向内容创作者、播客与多语言从业者，主打"字幕+翻译+配音"一站式流水线。核心痛点是商业配音平台（VEED、Descript、HappyScribe 等）按分钟收费、60 分钟视频动辄 24~48 美元（自报口径），而本项目本地部署零成本。

## 2. 核心架构与技术细节
v4.0 是重要迭代：安装器从 Miniconda/pip 迁移到 uv，配合 uv.lock 实现快速可复现安装；运行时升级至 Python 3.12、Torch 2.8.0+cu128（支持 RTX 50 系）、Gradio 6.20。ASR 栈整合 Whisper、Faster-Whisper 1.2.1、Whisper-Timestamped；TTS 栈涵盖 Edge-TTS、kokoro、F5-TTS、E2-TTS、CosyVoice（新增 Fun-CosyVoice3-0.5B，支持含韩语在内 9 种语言）。此外用 Demucs 做人声分离、yt-dlp 抓取、Deep-Translator 覆盖 100+ 语言、spaCy 做逐句切分。不再依赖 CUDA Toolkit 与 VS Build Tools，对受限企业电脑友好。

## 3. 竞品对比与生态站位
相较 ElevenLabs、Descript 等 SaaS，Voice-Pro 以本地化、无限用量取胜；相较纯 TTS 项目，它胜在端到端配音链路完整。README 直接列出与主流平台的每分钟成本对比作为卖点。star 约 11.7k、fork 约 1.7k（自报口径）。

## 4. 开发者反馈与局限性
最大局限是维护停滞：团队因转向 WeConnect 项目已暂停更新，故全部开源。仅在 Windows+NVIDIA GPU 上验证良好，Mac/Linux 未经验证。whisperX 因依赖冲突被移除。open issues 约 56（自报口径），社区支持有限。
