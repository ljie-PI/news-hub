# HKUDS/OpenSpace

## 1. 定位与痛点剖析
OpenSpace 由港大数据智能实验室（HKUDS）推出，定位为「面向 AI Agent 的技能管理层」。随着 Agent 积累的技能（skill）不断增长，如何在正确时机检索到正确技能、判断哪些技能真正有效、从失败中学习、并跨 Agent 与团队复用成功工作流，成为核心痛点。它试图把每次任务沉淀为可复用知识。

## 2. 核心架构与技术细节
基于 Python 3.12+ 构建，v2 围绕「检索—评估—共享—进化」全生命周期设计：包级浏览、质量摘要、任务轨迹上传，配套 Dashboard 与 TUI。支持私有化部署，让技能、数据与基础设施完全自控，并用真实任务结果驱动技能自我进化。

## 3. 竞品对比与生态站位
定位为「一层通吃」的技能中枢，兼容 Claude Code、Codex、OpenClaw、Hermès、nanobot 等多种 Agent，对标 MCP 生态但更聚焦技能资产的沉淀与治理，而非单纯工具调用。

## 4. 开发者反馈与局限性
已收获 7145 stars，热度高；MIT 协议开放。局限在于 v2 刚发布（2026-07），生态与第三方集成仍处早期，私有部署运维与技能质量评估的客观性有待验证。
