# The browser's main thread is expensive

## 事件背景

文章针对聊天、编辑器、地图等高交互页面的卡顿：主线程既串行执行 JavaScript 与事件，又承担样式计算、布局和绘制。六十赫兹屏幕每帧约十六点六毫秒，实用预算约十毫秒；超过五十毫秒的长任务会阻塞输入与绘制。批次冻结热度为三百六十七分、一百二十八条评论。

## 核心观点 / 产品机制

作者把治理分为“善用”与“绕开”主线程。前者将长任务切片并主动让出执行权，把高频更新批处理，再按用户意图排序、延后不可见内容；工具的恢复时机各异。后者让位移和透明度动画交给合成线程，以工作线程处理解析、图像等纯计算，并用可转移缓冲区减少复制。切片增加耗时，工作线程受通信成本与无文档对象模型权限所限；最佳优化仍是丢弃、合并或缓存不必执行的工作。
