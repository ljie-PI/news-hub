# expo/skills

## 定位与痛点剖析

expo/skills 是 Expo 团队维护的代理技能集，把 SDK、路由、原生模块、升级及 EAS 发布运维知识变成可按任务触发的指令。它面向用编码代理开发 Expo 与 React Native 应用的人，重点减少模型误用版本、混淆平台约束或凭记忆拼接工作流。批次快照为当日新增 216 星、累计 3547 星及 225 个分叉；查询时 REST API 为 3548 星、225 个分叉，两者分属冻结热度与当前状态。

## 核心架构与技术细节

默认分支是 main。仓库不是运行时框架，而是分层插件：`expo-overview` 先识别目标并路由，具体 `SKILL.md` 再引用按需加载的资料或脚本；每项还带 Codex 触发元数据。双插件清单适配 Agent Plugins 与 Claude Code/Cursor，MCP 配置连接 Expo 远端服务。检查脚本约束命名、正文行数、付费提示、目录同步和版本联动；技能按开源框架、付费 EAS 与实验能力分组。

## 竞品对比与生态站位

相较手写提示、通用规则或直接复制文档，它提供官方任务路由、版本化分发及跨代理安装，维护成本更低；相较只接 Expo MCP，技能负责静态流程与约束，MCP 才补充实时文档、构建、崩溃和模拟器操作，两者互补而非替代。优势是紧贴 Expo 工具链，代价是通用性弱，且 EAS 能力受套餐与账户条件限制；README 也明确文档、Expo CLI 与 EAS CLI 才是事实源。

## 开发者反馈与局限性

开放 issue #263 指出多项长参考文件缺少目录，最长达 605 行，暴露上下文检索负担。开放 PR #248 记录组件文档 slug 的大小写和连字符会导致 404，代理可能未核验 API 就写代码；PR #260 又报告远程版本源下旧建议实际无效。已合并 PR #266 删除验证器不接受的逐技能版本字段，评论确认 skills CLI 依据文件变化更新。可见维护响应活跃，但文档、客户端规范和 EAS 行为快速变化，仍有漂移风险。
