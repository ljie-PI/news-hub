# OpenScreen 2

## 事件背景
OpenScreen 2 于十月十一日登上 Product Hunt 日榜第五；冻结口径为一百三十二票、十条评论。官方 API 按 `post.id=1263181` 核对发布标识 `openscreen-2-3`，团队列出 Benjamin Freeman、维护者 Etienne Lescot 与 David Jayan。项目承接归档原仓库，主打免费、MIT、无账号、跨平台。

## 核心观点 / 产品机制
点击轨迹先被规划成镜头；本地转录可直接删词。外部代理经仅监听本机的 MCP 复用内置编辑工具：服务器和写权限分别开启，调用须带令牌，发布版还要求编辑器打开项目。删词工具以词 ID 锁定录音片段，再按时间生成剪口；英法语在 GPU 可追加 CTC 强制对齐，其他语言、CPU 或模型未就绪时回退 Whisper 的 DTW 时间。发布时无应用前预览；每次代理调用各成一个撤销步骤，仍可在时间线拖边修正。维护者宣称原生 GPU 导出在其参考笔记本约快十五倍，属于 maker 自报，非独立实测。

## 社区热议与争议点
官方 GraphQL 计数为十，但本次只取得四个顶层、五个回复节点，身份被脱敏；昵称由公开页逐字交叉。普通用户 Artur Kuznetsov 追问通用模型与专用视频 AI 的质量差距，产品方回复称效果依赖 Claude Code、Codex 等执行框架及模型，说明“AI 编辑”没有固定质量。普通用户 Gal Dayan 一面称赞免费、MIT、无水印，一面质疑误识别会把剪口落在句中；maker Etienne 承认尚无预审，只靠单步撤销和时间线修边，并明确非英法语时间更松。

## 行业影响与未来展望
它把录制、工程文件和代理工具连成本地工作流，为演示视频从云端黑箱转向可编程桌面软件提供样本。但价值仍取决于转录语言、所选模型与人工复核；项目格式和命令行仍可能破坏性变化。补上批量改动预览、可靠回滚及更多语言对齐后，才更适合无人值守生产。
